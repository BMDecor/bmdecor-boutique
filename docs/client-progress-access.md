# Where to see BM Decoración progress

One link, no account required, updates automatically:

👉 **https://github.com/orgs/BMDecores/projects/1**

## What you'll see

A board with every task in flight for your boutique — cards organised by status (**Todo** → **In Progress** → **Done**). Each card links to the full task description; click any card to read more. You can filter by label (e.g. `priority:high`, `brand:bm`) from the top bar, or just scan the columns.

## How to use it (60 seconds)

1. Open the link above in any browser. No sign-in needed.
2. The default view is a **Board** — columns left-to-right show progress.
3. Click any card to see the full description, discussion, and linked changes.
4. Green ✓ on a card means the task is Done and live on the preview site.
5. Purple **epic** tags mark large chunks of work made up of several smaller tasks.
6. Bookmark the page — the board updates every time we move a task.

## Things to know

- **Done** grows as we ship. Everything in that column is already live on the preview site.
- **In Progress** is what we're actively building right now.
- Tasks tagged `priority:high` are on the Monday review list. `priority:med` / `priority:low` are later.
- Tasks tagged `type:chore`, `scope:infra`, `scope:i18n` are internal tooling / plumbing — still progress, just not visible on the shop pages.
- Labels `brand:bm`, `brand:fb`, `brand:lg`, `brand:orac`, `brand:nm` mark tasks specific to each brand house.

# Как отслеживать прогресс проекта BM Decoración (Русская версия)

Одна ссылка, без регистрации, обновляется автоматически:

👉 **https://github.com/orgs/BMDecores/projects/1**

## Что вы увидите

Доска со всеми задачами по вашему бутику — карточки организованы по статусу (**Todo** → **In Progress** → **Done**). Каждая карточка ведёт к полному описанию; кликните — и увидите детали. В верхней панели есть фильтры по меткам (например `priority:high`, `brand:bm`), либо просто просмотрите колонки.

## Как пользоваться (60 секунд)

1. Откройте ссылку выше в любом браузере. Вход не нужен.
2. Вид по умолчанию — **Board**, колонки слева направо показывают прогресс.
3. Клик по карточке открывает полное описание, обсуждение и связанные изменения.
4. Зелёная галочка ✓ на карточке значит — задача сделана и уже на preview-сайте.
5. Фиолетовая метка **epic** — большая задача, состоящая из нескольких меньших.
6. Сохраните страницу в закладки — доска обновляется при каждом перемещении задачи.

## Что надо знать

- **Done** растёт по мере выпуска. Всё, что там — уже на preview-сайте.
- **In Progress** — то, что делается прямо сейчас.
- Задачи с меткой `priority:high` — на понедельничный обзор. `priority:med` / `priority:low` — позже.
- Метки `type:chore`, `scope:infra`, `scope:i18n` — внутренние инструменты / инфраструктура — прогресс тоже, но на витрине не видно.
- Метки `brand:bm`, `brand:fb`, `brand:lg`, `brand:orac`, `brand:nm` указывают принадлежность к бренду.
